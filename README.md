## Team Members

## Description
A Java-based Smart Classroom Management System that enables teachers and students to manage classroom activities such as attendance, assignments, marks, timetables, and announcements.

## Technologies
- Java
- OOP
- Collections
- File Handling / MySQL
- Git & GitHub

## Features
- Student Login
- Teacher Login
- Attendance
- Assignments
- Timetable
- Marks
- Announcements
